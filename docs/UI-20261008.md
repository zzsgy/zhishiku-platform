# 全站界面更新 · 2026-10-08

登录页原来没有加载公共样式，主站各模块的标题、表单、卡片和辅助页面也有视觉差异。本次将它们统一为深蓝导航、浅色内容区、舒展留白和清晰的内容层级。

- 登录页使用双栏布局，手机自动切换单栏；保留用户名、密码、CSRF、目标页面跳转和错误提示，新增显示/隐藏密码。
- 主站统一导航、顶栏搜索、账号菜单、卡片、按钮、表单、表格、弹窗与标签样式。平板与手机菜单使用一致的抽屉与键盘焦点规则。
- 工作台、收集、知识库、Wiki、关系图谱、书架、随笔记、灵感、金句、链接、自媒体、办公和设置使用同一套页面标题与间距。
- 知识、书籍、报告与献策的阅读页继续共用原有正文排版结构；修订、回收站、诊断、账号、管理后台和异常提示页也统一样式。
- 沿用明暗主题偏好，所有样式、图标和脚本来自本机资源；减少动态效果的系统偏好仍有效。
- 逐页检查发现链接库按不存在的 `created` 字段排序，修复为 `collected_at`，并补充空库与已有链接的回归验证。

视觉样式主要位于 `static/css/workspace.css`、`auth.css` 与 `admin-workspace.css`；正文与编辑器的结构仍在 `theme.css`。公共页面标题来自 `_page_head.html`，登录及异常页面共用 `registration/auth_base.html`。

隔离实例验证：28 个实际数据页面 × 5 组视口/主题组合，合计 140 次页面检查；另外 11 个详情/账号页面 × 4 组组合，合计 44 次检查。未发现整页横向溢出或页面脚本错误。登录与退出、菜单、密码显示、书籍弹窗、办公/设置标签，以及原有导入、编辑、草稿保护和移动端流程通过浏览器复核。链接库和原有完整浏览器流程两个针对性回归均通过。

本次无需升级数据库或安装依赖。发布后须生成静态资源并重启本机服务，让模板、脚本和样式同时生效；静态资源沿用版本化 URL。
