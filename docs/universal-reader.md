# 书架通用阅读器

阅读入口：书架卡片的「开始阅读 / 继续阅读」。所有预览、原件、图片和续读接口均沿用登录与 CSRF 边界。

## 阅读方式

| 格式 | 默认阅读 | 边界 |
|---|---|---|
| PDF | 本地 PDF.js 原版页面、文字层、原有链接、嵌入目录 | 扫描件可看原版；无文字层时搜索/划词需 OCR。不会执行 PDF 脚本。 |
| Word DOCX | 按原顺序展示标题、段落、编号、常见文字样式、图片、表格及合并单元格 | 重排正文并非 Word 打印版；复杂公式、浮动布局请对照原件。 |
| Markdown | 共享主题的标题、列表、链接、表格、代码块 | 不执行嵌入脚本。 |
| TXT / TEXT | 自动识别 UTF-8、带 BOM 的 UTF-16、GB18030；保留段内换行 | 不按关键词猜测标题或代码。 |
| HTML | 清理后的正文与结构 | 脚本、事件、活动嵌入不执行。 |
| CSV / TSV / XLSX | 可横向滚动的表格 | XLSX 使用已保存的值，不计算公式。图表请对照原件。 |
| PPTX | 按幻灯片展示可提取的正文及表格 | 图片、公式、图表和复杂布局请对照原件。 |
| RTF | 解码后的文字 | 格式、图片与公式请对照原件。 |
| JSON / 日志 / 代码等 | 等宽预格式化文字 | 保留缩进与原有换行。 |
| 旧 Word DOC | 保存与下载原件、明确转换提示 | 另存为 DOCX 或 PDF 后可在线阅读。 |

字号、行距、正文宽度、阅读背景（跟随主题/白/纸张/夜间）、目录、搜索、笔记、专注模式统一在阅读器内。PDF 字体遵循原件，由缩放调整大小。未包含嵌入目录的 PDF 使用真实页码导航，不猜测章节。

## 原件与续读

- `bookshelf.reader` 只生成显示预览，不修改原件、索引正文或 Asset 元数据。
- 阅读位置独立保存在 `ReaderPosition`，按账号与书籍唯一。原件 SHA-256 改变后旧位置失效。
- PDF 保存页码与页内滚动比例；正文保存滚动比例。排版参数一并保存。
- 自动记录不会重写原有 `Book.progress/status/total_pages`，原有书籍记录与手动进度接口保留。
- 新增迁移 `0006_readerposition` 只创建续读表，没有数据重写或重导。
- PDF 原件接口支持经过登录验证的单段 Range/HEAD，下载时返回未经改动的原件。其他格式按附件下载。
- Word 插图通过限定到该书原件的图片接口访问，不暴露服务器任意路径。
- 解析失败仍保留下载原件与重开入口；来源网页可以由用户主动重新抓取。

## 依赖与验证

PDF.js 6.4.299 使用 Mozilla 官方 npm 包的 legacy 构建，内含浏览器兼容补丁。JS、worker、CMap、字体、WASM 和 CSS 均随项目本地分发，无外部 CDN。原始上游文件未修改，许可证、包完整性和逐文件哈希记录在 vendor 的 provenance 中。RTF 使用 BSD-3-Clause 的 striprtf 0.0.33，原模块与许可证本地分发。

服务端测试涵盖原件/Range/登录/CSRF、扫描 PDF、Word 结构与图像、编码、HTML 安全、RTF、旧 DOC 的明确回退，以及按账号续读、原件变更后位置失效。浏览器验证涵盖真实 83 页 PDF 的代表页、搜索、高亮、跳页续读、加密文件、Word 图表、代码、手机与深浅色主题。复杂文档仍应对照原件；代表页检查不代表逐页人工审阅。
